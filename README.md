### Hey, I'm Rob 👋🏻

I'm a Senior Software Engineer specialising in Design Systems, currently building [Hearth](https://github.com/utilitywarehouse/hearth) at Utility Warehouse. My focus now is making Hearth AI-native, enabling agentic workflows for the product teams it supports.

What I actually do:

* Build and scale the core libraries: CSS-styled React components, design tokens, iconography, illustrations, and typography
* Embed accessibility in from design through to shipped code
* Help shape how AI-assisted workflows fit into UI development
* Treat documentation as a first-class product, written for engineers and LLMs alike
* Automate Figma-to-code pipelines, keeping design and code in sync
* Underpin Hearth's libraries with Storybook, visual regression testing, and custom dev tooling
* Support adoption across multiple product teams, building direct feedback loops across brand, UX, product and engineering
* Mentor engineers and run knowledge-sharing sessions for the frontend community

It's been a bit of a winding path: I started out as [an artist](http://rm-phoenix.co.uk/), studying computer networking as a mature student, then moved through backend and frontend before landing in design systems.

I'm based in the North Wales countryside with my family and our many animals, usually reading, walking, or fixing something.
